# Публичный API-фид Avito «Хранилище РУ»

Этот каталог предназначен только для официальной автозагрузки Avito.

- `avito-feed.xml` — безопасная версия с `DateBegin` в 2099 году.
- `media/` — 18 уникальных B2C-креативов без промышленных складских сцен.
- Основной сайт «Хранилище РУ» не используется.

Сборка безопасной версии:

```bash
python3 ../build_avito_api_feed.py \
  --base-url https://raw.githubusercontent.com/Vlseferov/hranilishche-avito-feed/main
```

Фид обслуживается отдельным техническим репозиторием и не содержит ключей API
или персональных данных.
